# Project Hub — v0.15

Open Sources from the library or run `uv run python -m gameagent.qt_sources`. Select a game and click Actualiser. The explorer reads checked-out files under data/upstream/ID, lists docs and licenses, supports filtering and bounded text preview. Source inspection does not execute code. Separate explicit actions configure/open installed original applications and local WebUI. The classic hub remains available. See [technical reference](technical-reference.md).
