# Game artwork / Illustrations

Obsidian Studio v0.15 generates original deterministic procedural landscape covers with Pillow (no network download). Override a profile with artwork you are entitled to use:

| Game | Directory |
|---|---|
| Brown Dust 2 | brown_dust_2/ |
| NIKKE | nikke/ |
| Genshin Impact | genshin_impact/ |
| Honkai: Star Rail | honkai_star_rail/ |
| Wuthering Waves | wuthering_waves/ |
| Neverness to Everness | neverness_to_everness/ |

Name the file banner.png, banner.jpg, banner.jpeg or banner.webp. A wide image (e.g. 1600 × 900 or wider) is recommended; the renderer crops/scales it to the target slot. Restart GameAgent after changes (memory cache). The old Tkinter banner applies additional shading. No official game artwork is included. Do not commit images without redistribution rights.

See [Obsidian UI](../../docs/obsidian-ui.md).
